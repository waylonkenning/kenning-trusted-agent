# Community

Use the public GitHub repository as the community entry point.

- Issues: reproducible bugs, deployment defects, and documentation errors.
- Discussions: questions, proposals, and roadmap conversation when enabled.
- Pull requests: reviewed code, tests, and documentation changes.
- Security: private vulnerability reporting through [SECURITY.md](../SECURITY.md).
- Conduct: follow [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md).

The private maintainer delivery board is not public. A future public roadmap
may mirror product-level work without exposing customer evidence, production
approvals, or security findings.
