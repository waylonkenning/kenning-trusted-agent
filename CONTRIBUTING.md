# Contributing

Thank you for contributing to Kenning Trusted Agent.

1. Create or select an issue that describes the change.
2. Keep changes focused and include tests for new behavior.
3. Run `bash scripts/public_validation.sh` or the equivalent commands in
   `docs/DEVELOPMENT.md`.
4. Do not commit credentials, customer data, browser state, or deployment
   parameter files.
5. Open a pull request with scope, tests, documentation, security, and
   migration notes.

Use Simplified Technical English in product copy and documentation. Keep
deployment changes customer-owned and provider-specific unless the change is
part of the public AWS single-tenant package.

Security reports must follow [SECURITY.md](SECURITY.md), not a public issue.
Review [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) before participating.
