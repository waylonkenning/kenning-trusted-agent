# Support

Kenning Trusted Agent is a self-hosted open-source project. The public
repository does not provide a hosted API, hosted portal, uptime commitment, or
operator access to a customer deployment.

## Community support

- Use GitHub issues for reproducible bugs and documentation corrections.
- Use GitHub Discussions for questions and design proposals when Discussions
  are enabled on the repository.
- Include the release version, operating system, Python and Node versions,
  deployment mode, and a redacted reproduction. Do not include credentials,
  customer data, private URLs, account IDs, or raw logs.

## Deployment support

The AWS account owner supports AWS quotas, network routes, DNS, certificates,
identity providers, backups, retention, CloudWatch, and incident response.
The project maintainers support the public package and its documented
self-hosting path. Azure and Kenning-managed hosting are not supported in
release 1.0.0.

Commercial implementation or managed-service arrangements, if offered later,
are separate from the MIT-licensed source and are not required to use it.

## Version policy

The latest minor release receives normal maintenance. Security reports are
handled privately under [SECURITY.md](SECURITY.md). Older releases receive
best-effort help unless a security fix is backported by the maintainers.
